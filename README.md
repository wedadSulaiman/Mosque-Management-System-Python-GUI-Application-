# Mosque Management System (Python GUI Application)

This project is a **Mosque Management System** developed using **Python**, **Tkinter**, and **SQLite**.  
It provides a graphical user interface (GUI) to manage mosque records, including adding, searching, updating, deleting, displaying mosques, and viewing mosque locations on a map.

---

## Project Overview

The system allows users to manage mosque information such as:
- ID
- Name
- Type (Mosque / Grand Mosque)
- Address
- Coordinates (Latitude, Longitude)
- Imam Name

The application stores data locally using an SQLite database and supports displaying mosque locations on an interactive map using Folium.

---

## Features

- Graphical User Interface using Tkinter
- Add new mosque records
- Delete mosque records by ID
- Update Imam name for an existing mosque
- Search mosque by name (with close-match suggestions)
- Display all mosque records
- Display mosque location on a map using coordinates
- Scrollable record display area
- Input validation and error handling

---

## Technologies Used

- Python 3
- Tkinter (GUI)
- SQLite3 (Database)
- Folium (Map visualization)
- Webbrowser (Open map in browser)
- Difflib (Fuzzy search for mosque names)
